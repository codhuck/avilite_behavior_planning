после остановки тест разрешает движение зелёным. Состояния группы светофоров
могут влиять друг на друга: на west во втором повторе 949 оказался зелёным
без отдельного ожидания. Фактические ожидания перечислены в light_holds.

## Исправления по результатам проездов

1. Добавлен **HDMapLaneFollowingPlanner**: исключает боковые рёбра графа.
   Предыдущий глобальный план содержал резкие смещения на ширину полосы,
   которые ReferencePathPlanner не превращал в выполнимое перестроение.
   Новый вариант строит более длинный маршрут по связанным полосам.
2. В HDMapRuleVelocityPlanner добавлены ограничение скорости по кривизне
   и распространение тормозного ограничения назад по маршруту.
3. Самопересекающийся маршрут теперь отвергается понятной ошибкой до движения.
   На диагностическом маршруте расчёт позиции прыгнул с 194 на 469 м
   при перемещении машины всего на 9 см. Это выявило необходимость отдельного
   отслеживания повторных проходов; поддержка таких маршрутов не заявляется.
4. Проверка успеха усилена: кроме цели/столкновений/сигналов требуется
   отклонение ≤1 м. Выдержка Stop проверяется по записанному движению,
   а не только по внутреннему событию планировщика.
5. Обновлены три установленных профиля и маршруты. Старые YAML сохранены
   рядом с профилями с суффиксом backup. Запись INFO и телеметрии включена.

Одна только кривизна не устранила плохое перестроение: в первой диагностической
серии отклонение west достигало 1,83 м. Поэтому улучшение финальной серии
связано прежде всего с исправлением выбора маршрута, а не с настройкой
контроллера на той же траектории. Во второй серии два проезда самопересекающегося
маршрута завершились неуспешно; их результаты сохранены, а не исключены из истории.

Диагностические данные: `logs/hdmap_validation_curves/` и
`logs/hdmap_validation_lane_following/`. Предыдущий отчёт:
[VALIDATION_PREVIOUS.md](VALIDATION_PREVIOUS.md).

## Воспроизведение

Закрыть AVLite и других клиентов, продвигающих время CARLA. Сервер должен
работать на localhost:2000 с Town10HD_Opt, без посторонних автомобилей.

```bash
conda activate avlite-carla
cd /path/to/avlite
PYTHONNOUSERSITE=1 python tools/run_hdmap_scenarios.py --repeats 2 --max-sim-time 600 --output logs/hdmap_new_run
PYTHONNOUSERSITE=1 python tools/audit_hdmap_runs.py logs/hdmap_new_run
PYTHONNOUSERSITE=1 python tools/report_hdmap_validation.py logs/hdmap_new_run
```

В GUI выбрать hdmap-stop-west / hdmap-stop-east / hdmap-junctions.
Обычный GUI не расставляет тестовых пешеходов и не переключает светофоры:
он наблюдает текущее состояние CARLA. Файлы каждого проезда — `logs/hdmap/`.

## Область проверки

CARLA 0.9.16, Town10HD_Opt, шаг 0,05 с, скорость маршрута до 3 м/с,
реальная физика Audi A2, ReferencePathPlanner и StanleyController.
Полные серии используют динамические данные напрямую из CARLA, не распознавание
камерой. Светофоры и пешеход — управляемые тестовые объекты, случайный трафик
отключён. Пешеход перемещается из зоны тестом; прогноз его движения не проверен.

Новый маршрут без перестроений не заменяет полноценное планирование перестроений.
Самопересечения не поддерживаются. Жёлтый всегда требует остановки; дилеммная
зона не реализована. Геометрия OpenDRIVE приближена дискретной линией,
освобождение перехода моделируется упрощённо. Успех не доказывает корректность
во всех дорожных ситуациях или нахождение всего кузова внутри полосы.
Переключение целых стеков планирования/восприятия отдельным supervisor не реализовано.


## Проверка установленного стека

После финальной серии выполнена короткая проверка профиля hdmap-junctions:
40 шагов по 0,05 с через настоящий CarlaBridge, RGB/LiDAR, SyncExecuter
и CarlaRegulatoryTask. Запись телеметрии и чтение 15 светофоров подтверждены.
[Результат](../logs/hdmap_validation_expanded_final/stack_smoke.json).

Она выявила стартовую нулевую позицию CARLA на первом шаге. Удалено запоминание
этой позиции как основания пропускать ранние правила; регрессионный тест
проверяет возврат к первому Stop после исправления координат. Это последнее
исправление проверено тестом и мостом; полные шесть маршрутов выше выполнены
до него, с корректной стартовой позицией после предварительных тиков.
