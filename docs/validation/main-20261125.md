Run the full plugin tests from this directory:

```bash
PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 python -m pytest \
  --rootdir=.. --import-mode=importlib -q tests
```

The explicit root argument matters. Pytest resolves its root before reading
`addopts`; placing `--rootdir=..` there did not select the parent and caused
relative-import errors before test setup. The redundant ini argument was removed.
The documented command and CI already pass the root explicitly.

## Integration boundaries

Ordinary-executor support needs the local core changes. On released AVLite
0.6.7 the plugin keeps its synchronous runtime adapter. Parking mission hooks
also still use that adapter. The core API names remain a proposal, not an
upstream-approved interface.

Live ROS worker stack replacement is not implemented: it needs remote
publication and acknowledgement, not a change to local mirror pointers. The
shared observation wire format and multi-producer ownership also need agreement.
No new live CARLA run or real-camera accuracy claim follows from these checks.
